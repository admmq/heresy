* Installation

** use-package
#+begin_src elisp :eval query
  (use-package stuff
    :vc (:url "https://github.com/admmq/heresy.git"
         :branch "main"
         :rev :newest
         :lisp-dir "emacs")
    :config
    (stuff-config-set-font 18)
    (stuff-config-set-variables)
    (stuff-packages-load-packages))
#+end_src
